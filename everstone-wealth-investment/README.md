# Everstone Wealth Investment — website draft

This folder contains an initial, self-contained website concept for **Everstone Wealth Investment**. It is intentionally separate from the existing Real Wealth Edge files in the repository root.

## Files
- `index.html` — public-facing company website draft
- `styles.css` — responsive green, cream and gold visual system
- `dashboard.html` — client portal visual preview (not connected to live data)

## Preview
Open `index.html` in a browser, or enable GitHub Pages with the repository root as the publishing source and browse to `/everstone-wealth-investment/`.

## Important production limitations
This is a front-end concept, not an operating investment business or production financial platform. The client dashboard is a non-functional visual preview. There is no backend, account authentication, database, identity verification, payment processing, transaction ledger, deposit/withdrawal handling, investment execution or live account data.

Before offering regulated financial services or accepting client funds, the company must obtain the applicable legal and regulatory advice and authorisations, verify its business identity and disclosures, and contract with suitable regulated banking/payment providers. A production portal also requires secure server-side authentication, role-based access, encryption, audit trails, monitoring, backups, privacy controls and independent security testing.

Replace all placeholder contact information only with verified company details. Do not publish unverified licences, regulatory approvals, performance claims, testimonials or client records.
